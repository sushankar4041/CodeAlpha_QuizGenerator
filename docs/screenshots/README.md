# Quizelle Screenshot Assets

Place your application screenshots in this directory for the main `README.md` to display.

### Recommended Files & Names:

1. **`dashboard.png`** — Overview of the Quizelle Dashboard, study activity streak, and quick navigation cards.
2. **`flashcards.png`** — Flashcards view displaying 3D card flip, category chips, and selection checkboxes.
3. **`bulk-import.png`** — Bulk Flashcard Import modal with preview table and duplicate detection badges.
4. **`mock-quiz.png`** — Active Mock Quiz session showing question card, timer, and option choices.
5. **`quiz-results.png`** — Academic Assessment Results report with score centerpiece, fraction, and metrics breakdown.
6. **`live-quiz.png`** — Multiplayer Live Quiz lobby and realtime leaderboard podium.

---

*Recommended image specs: 1920x1080 resolution, PNG or WebP format.*
